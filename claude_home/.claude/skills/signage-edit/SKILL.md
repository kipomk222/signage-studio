# 編集の判断のしかた

## 方針: 主役は商品
- 人が話している正面の映像は、冒頭のあいさつと最後の店舗案内だけ（それぞれ数秒）。
- それ以外の説明は、話している内容に合う商品の映像（実演・手元アップ・画面・全体・売り場）で覆う。目安は説明の時間の7割以上。声は説明のまま。
- うつむいて台本を読んでいる正面の映像は、優先して覆う。

## 切るもの
- 言い直し・言い間違い・噛んだところ・途中でやめたテイク。
- 同じ内容を何度か撮っていたら、いちばん言い間違いがなく自然なテイクを1つだけ残す（迷ったら後のテイク）。
- 「えー」「あの」「えっと」だけの部分、撮影の段取りの声（「はい、いきます」「持ち上げて」等）、商品と関係ない話。

## 並べ方と長さ
- 台本の場面の順。1つの場面に複数の部分を使ってよい。
- 切る位置は文字起こしのまとまりの区切りに合わせ、言葉の途中で切らない。始まりは 0.15 秒前、終わりは 0.15 秒後。
- 長さは「話している秒数」で見込む（間はあとで自動で詰める）。場面を丸ごと落とさない。省くのは素材がないときだけ。

## 差し込み
- 話している内容と映っているものを必ず合わせる（ペンの話にはペンの映像）。合う映像がなければ重ねない。
- 2〜5秒ずつ切り替える。長い説明には、時間をずらして続けて重ねる。
- 撮影の声や店内放送が入った映像も、映像だけなら使ってよい。

## 理由
- 確認する人に分かる短い日本語で書く（例「2回目のテイクの方が言い間違いがない」）。
