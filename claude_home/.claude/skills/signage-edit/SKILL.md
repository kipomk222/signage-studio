# 編集の判断のしかた

## 切るもの
- 言い直し・言い間違い・噛んだところ・途中でやめたテイク。
- 同じ内容を何度か撮っていたら、いちばん言い間違いがなく自然なテイクを1つだけ残す（迷ったら後のテイク）。
- 「えー」「あの」「えっと」だけの部分、撮影の段取りの声（「はい、いきます」「もう一回」等）、商品と関係ない話。

## 並べ方
- 台本の場面の順。1つの場面に複数の部分を使ってよい。
- 切る位置は文字起こしのまとまりの区切りに合わせ、言葉の途中で切らない。始まりは 0.15 秒前、終わりは 0.15 秒後。

## 差し込み
- 話していない映像（実演・手元アップ・商品の全体）を、内容が合う説明の部分に重ねる。声は説明のまま。
- 1〜8秒。参考にしている店頭動画は、説明3〜5秒・実演2〜3秒くらいのテンポで切り替わる。

## 理由
- 確認する人に分かる短い日本語で書く（例「2回目のテイクの方が言い間違いがない」）。
