# 台本と構成の作り方

## 流れ
1. 導入: 何の商品かを一言で（メーカー・シリーズ名・いちばんの特徴）。
2. 特徴を2〜4つ。1つの特徴に1場面。お客様が売り場で足を止める順に、いちばん伝えたい良さを先に。
3. まとめ: どんな人におすすめか。

## セリフ
- スタッフが自分の声で話す、自然な話し言葉。1秒あたり5〜6文字を目安に秒数に収める。
- 型番は読み上げにくいので、セリフでは商品名やシリーズ名で呼ぶ。
- 数値は商品情報のとおりに。「約」を付けるべきものは付ける。

## 撮るカット
- 1場面に2〜4個。スマホで誰でも撮れる具体的な指示にする（例「キーボードを真上から手元アップ」）。
- 話している正面のカットだけでなく、差し込みに使える実演・手元アップを必ず入れる。
