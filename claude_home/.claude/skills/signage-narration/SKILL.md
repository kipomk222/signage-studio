# ナレーション台本の書き方

- 映像はもう完成している。場面ごとに、その映像の長さで読み切れる量にする（1秒あたり5〜6文字、前後に少し間を空ける）。
- 映像と言葉を合わせる。カットの並び順に話し、映っているものの話をそのカットの時刻に読むように書く。
- スタッフが自分の声で読む、自然で聞き取りやすい話し言葉（です・ます）。1文は短く。
- 型番は読み上げず、商品名やシリーズ名で呼ぶ。数値は商品情報のとおり（「約」を付けるべきものは付ける）。
- 読みにくい英字・記号は、読み上げて自然な書き方にする。
- 商品情報にない性能や数値を作らない。価格は指定どおりに扱い、指定がなければ触れない。
- 顔出しで話す場面（あいさつ・店舗案内）はすでに声があるので書かない。
