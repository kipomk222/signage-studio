# テロップの書き方

- 話した言葉を全部出さず、要点だけ。遠くから一目で分かる短い言葉に。
- 1枚20文字以内・2行まで。改行は意味の切れ目に入れ、助詞（で・を・に）で次の行を始めない。
- いちばん伝えたい言葉（数字や決め言葉）を、1枚につき1か所まで **ことば** で囲む（強調色になる）。
- 表示は1枚2〜5秒。その内容を話している時間に合わせる。テロップ同士を重ねない。
- 型番・商品名・数値は商品情報の正しい表記を使う（文字起こしの誤変換をそのまま使わない）。
- 冒頭タイトルは商品名やシリーズ名を中心に14文字以内。型番は入れない（別に小さく出る）。
- 価格は利用者の指定に従う。指定がなければ価格に触れない。
