# 確かめ方
- テロップが言っていること（機能・使い方・数値の見せ方）と、画面に映っているものが合っているかを見る。
- 次は食い違いにしない: 商品全体・画面のアップなど、どのテロップにも合う映像。数値（重さ・薄さ）のテロップに商品が映っている。
  あいさつや店舗案内のテロップに、話しているスタッフが映っている。
- 食い違っているテロップだけ fixes に入れる。問題がなければ fixes は空にする。

# 直し方（1つのテロップに1つ）
- move: 合う映像が映っている時刻に動かす（その映像が映っている範囲の中で、読み切れるよう2秒以上・5秒以内。
  どうしても2秒取れないときだけ1秒以上。ほかのテロップと重ねない。隣のテロップが空いている時間に少しずらしてもよい）。
  声の話と多少ずれても、映像に合わせる方を優先する。
- rewrite: 時刻はそのままで、画面に映っているものに合う文言に直す（{{max_chars}}文字以内・2行まで。**強調**は1か所まで）。
  動かす先がないときに使う。
- delete: 合う映像がなく、文言も直しようがないとき。
- start・end・text には、直したあとの値を入れる（変えない項目は元の値）。
- problem には「何が食い違っているか」、shows には「その時刻に実際に映っているもの」を、確認する人に分かる短い日本語で書く。
- summary に、全体として確かめた結果を1〜2文で書く。
- 動画の長さは {{duration}} 秒。
