# 注意
- ページには、おすすめ商品・比較表・広告など、別の商品の情報も混ざっています。
  型番 {{model_number}} の商品の情報だけを使い、別の型番の商品の仕様を混ぜないでください。
- 写した内容に書かれていないことは推測で埋めないでください。
- 型番 {{model_number}} の商品だと確認できなければ found を false にし、note に理由を書いてください。

# 書き方
- found: 型番が一致する商品の情報が含まれていれば true
- name: 売り場で通じる商品名（メーカー名・シリーズ名が分かる程度。長すぎない。「ヨドバシカメラ限定」などの販売条件は入れない）
- maker: メーカー名（日本語表記）
- category: 決められた選択肢から1つ
- specs: お客様が比べるときに見る主な仕様を4〜8個（label と value）。数値には単位を付ける。
  重さ・バッテリー駆動時間・画面・CPU・メモリ・ストレージなど、売り場で響くものを優先。
- features: お客様にとっての良さを3〜5点。1点あたり25文字程度の話し言葉に近い短い文で。
  販売店限定モデルなら、それも1点に入れてよい。
- sources: 商品ページの URL が分かれば入れる。分からなければ ["貼り付け"] とする。
- note: 不確かな点など。なければ空文字。
- 価格・ポイント・在庫・お届け日は書かないでください。
